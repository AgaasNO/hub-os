# Contributing

This repo is part of the collaborative core. Read [`hub-map`](https://github.com/gabriellindberg-png/hub-map) first if you haven't.

## Workflow

- **Never commit to `master` directly.** Work on a branch; merge via pull request. (`master` is branch-protected — non-admin pushes are rejected.)
- **Branch naming:** `feat/<short-desc>`, `fix/<short-desc>`, `docs/<short-desc>`, `chore/<short-desc>`.
- **One approval** to merge a PR.

## Specific to hub-os

hub-os is a **framework**, not a service — mostly `FRAMEWORK.md`, a copy-able `skeleton/`, and templates. Contributions flow **one direction only: up** (a real incident in a hub → a `USER.md` learning → a `FRAMEWORK.md` reflex). Don't add speculative framework rules; promote rules that proved themselves in a real hub. See `FRAMEWORK.md` Section 8 (promotion rules).
